# 红球狗狗 · Dog Platformer

一款让你在**工作紧张之余放松身心**的横版过关小游戏，灵感来自经典《超级玛丽》，但主角是一只圆滚滚的红色狗狗。

> 下班路上、午休间隙，掏出手机跳两关——躲尖刺、踩弹跳垫、吃骨头变大，找回小时候玩红白机的快乐。

## 特点

- 🐶 **原创狗狗主角**：不是玛丽奥，规避版权风险
- 🎮 **3 个精心设计的关卡**，难度逐级提升，多路线探索
- ❤️ **独立生命血条 + 生命数 + 护盾**，伤害分级（尖刺/炮弹更致命）
- 🦴 **5 种道具**：骨头变大、宝石回血、红心回满血、无敌星、羽毛二段跳
- 👾 **4 种敌人**：刺球、飞虫、跳跳、追踪无人机，另有尖刺/移动尖刺/炮台/深坑多种威胁
- 🏁 **过关门槛**：攒够骨头才能解锁终点旗帜，逼你深入险境而非一路跳过
- 🎵 **纯代码合成音乐与音效**：无任何音频资源文件
- 🖼️ **纯 Canvas 绘制**：零游戏引擎、零第三方依赖

## 玩法与规则

### 操作

| 按钮 | 功能 |
| --- | --- |
| 屏幕左下 `←` `→` | 左右移动 |
| 屏幕右下 `跳` | 跳跃（支持二段跳、土狼时间、跳跃缓冲） |
| 左上角 `音乐` | 背景音乐开关 |

### 生命与伤害

- 生命血条共 **3 格**；被敌人碰到扣 **1 格**，踩尖刺 / 被炮弹打中扣 **2 格**
- 血条清零，或掉进深坑，都会死亡；共 **3 条命**
- 生命耗尽后进入答题复活环节（答对才能重来）

### 道具

| 道具 | 效果 |
| --- | --- |
| 🦴 骨头 | 变大、跳得更高；同时也是过关要收集的目标 |
| 💎 宝石 | 回 1 格血（血满则加护盾） |
| ❤️ 红心 | 回满血（血满则加生命） |
| ⭐ 无敌星 | 4 秒无敌 |
| 🪶 羽毛 | 获得二段跳 |

### 过关条件

每一关需要**收集足够数量的骨头**，终点旗帜才会从灰色解锁为红色。

## 构建与安装

### 环境要求

- JDK 17
- Android SDK（compileSdk 34 / minSdk 24）
- Gradle 8.7（项目自带 wrapper，无需手动安装）

### 构建 Debug APK

```bash
./gradlew :app:assembleDebug
```

产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

### 安装到手机

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 技术实现

- **语言**：Kotlin
- **渲染**：`SurfaceView` + `Canvas` 纯矢量绘制，虚拟分辨率 1280×720，全屏自适应无黑边
- **音频**：`AudioTrack` 代码合成（正弦波 + 二次谐波 + 包络），零音频文件
- **架构**：单游戏线程（永不退出）+ 关卡数据驱动；触摸线程只发输入与指令，关卡重建只走游戏线程，杜绝并发竞态

## 项目结构

```
app/src/main/kotlin/com/doggame/platformer/
├── GameView.kt       # 游戏主逻辑：关卡、物理、碰撞、渲染、HUD
├── MainActivity.kt   # 入口 Activity：全屏沉浸式
└── SoundEngine.kt    # 代码合成音效与背景音乐
```
